⚠️ 色彩模式為 RGB — 需轉換為 CMYK 再交稿

偵測到 RGB。印刷使用 CMYK 四色油墨，直接送印 RGB 將由廠商自動轉換，可能造成顏色偏差。

  1. Photoshop：影像 → 模式 → CMYK 色彩，確認後另存新檔
  2. Illustrator：檔案 → 文件色彩模式 → CMYK
  3. InDesign：匯出 PDF 選「印刷品質」，自動嵌入 CMYK
  4. 轉換後開啟 Ctrl+Y（色彩校樣）目視確認顏色

    📐 如何製作出血

    稿件尚未包含出血，建議加上 3mm 後再交稿。

    1. Illustrator / InDesign：文件設定 → 出血值，背景延伸至出血線外，匯出 PDF 時勾選「包含出血設定」。
    2. Photoshop：擴大畫布每邊各加出血 mm（—），背景填滿後存 PDF。
    3. 確認：Acrobat「印前檢查 > 頁面尺寸」確認含出血後總尺寸正確。
