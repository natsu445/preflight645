⚠️ 色彩模式為 RGB，需轉換為 CMYK

偵測到檔案使用 RGB 色彩模式。印刷機使用 CMYK（青、洋紅、黃、黑）四色油墨，若直接送印 RGB 檔案，印刷廠會自動轉換，可能造成顏色偏差（尤其橘色、紫色、亮色）。

  1. Photoshop：影像 → 模式 → CMYK 色彩，確認顏色後另存新檔
  2. Illustrator：檔案 → 文件色彩模式 → CMYK
  3. InDesign：匯出 PDF 時選「印刷品質」設定檔，自動轉換
  4. 轉換後：開啟色彩校樣（Ctrl/Cmd+Y）目視確認顏色是否符合預期，再交稿

📐 如何製作出血

稿件尚未包含出血，建議加上 3mm 後再交稿。

  1. Illustrator / InDesign：文件設定 → 出血設為對應值，背景延伸至出血線外，匯出 PDF 時勾選「包含出血設定」。
  2. Photoshop：擴大畫布每邊各加出血 mm（換算：—），背景填滿後存為 PDF。
  3. 確認：Acrobat「印前檢查 > 頁面尺寸」確認含出血後的總尺寸正確。
